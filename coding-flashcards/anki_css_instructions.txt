ANKI FLASHCARD CSS INSTRUCTIONS

Purpose
These CSS rules provide simple visual hierarchy for coding-related Anki flashcards.

The generated cards should use predefined HTML wrapper classes in the Front and Back CSV fields. These CSS rules style those wrappers inside Anki.

Core principles
- Keep the design minimal and readable.
- Use badges for card type and technology labels.
- Make code/syntax answers visually prominent.
- Keep explanations visually secondary.
- Use warm colours for common mistakes and warnings.
- Support both normal mode and Anki night mode.
