# Engineered Prompts

A collection of engineered prompts for use with AI assistants, language models, and agentic workflows.

This directory contains reusable prompt templates designed to produce more consistent, structured, and useful outputs across different tasks. Prompts may cover areas such as content generation, coding support, research, summarisation, data transformation, flashcard creation, planning, and workflow automation.

When adding a new set of prompt instructions, please include the following:

## Purpose
Briefly describe what the prompt is designed to do.

## Use Case
Explain when this prompt should be used.

## Usage instructions
Describe how the prompt should be used. 

## Prompt Files
Provide the actual prompt instructions.

## Input Format
Describe what information the user should provide.

## Output Format
Describe the expected output structure.
